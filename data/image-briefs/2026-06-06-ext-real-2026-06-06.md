# Paperclipalypse Feature Image Brief

Run: 2026-06-06-ext-real-2026-06-06
Winner: Gemini Flash
Winning joke: The Hero's Dilemma

## Gemini Image Prompt

```text
Create one polished web feature image for Paperclipalypse.

ASPECT RATIO: exactly 2:1, horizontal wide banner.

This must be a clear illustrated comedy poster, not a busy comic page.

Layout:
- LEFT 40%: one clean full-color illustration. A charming anthropomorphic metallic paperclip stand-up comedian at a microphone on a small stage, with a simple diner scene behind him: one choking diner, one calm antisocial diner eating fries. Keep this side simple and uncluttered.
- RIGHT 60%: one flat dark charcoal poster panel with a bronze frame. This panel is mostly typography. Use large cream-white plain sans-serif lettering, like a clean printed poster, not distorted hand lettering.

TEXT ACCURACY IS THE TOP PRIORITY. The right poster panel must contain exactly these lines, with normal spaces between words:

I'm so antisocial that being a hero
is my worst nightmare.

A guy started choking at a diner.
I know the Heimlich maneuver,
and I'm fine with bruising a rib
to save him.

But if it works, he survives.
And if he survives, I have to make
awkward small talk while the whole
restaurant claps.

I kept eating my fries.
I figured he'd want his privacy.

Rules:
- Spell every word correctly.
- Do not merge words together.
- Do not invent letters.
- Keep the text entirely inside the right panel with generous margins.
- Do not add any other visible words, signs, captions, labels, logos, watermarks, signatures, or fake microtext anywhere else.
- If space is tight, make the illustration simpler and the right text panel larger. Do not remove, rewrite, or garble the text.
```

## Attach The Approved Image

Use Google Gemini image generation for the bitmap. Open a fresh Chrome window first, generate the image, then open Gemini's generated preview image and save or capture the smaller 1024x506 preview. Never use Gemini's full-size export for this project. Low-quality images must be rejected and regenerated until the QA checklist passes.

## Feature Image QA

Before approval, inspect the saved Gemini preview image against this checklist:

- The image is Gemini's smaller generated preview image, saved or captured from the preview viewer. Do not use Gemini's full-size export for this project.
- The image is approximately 2:1, landscape, and at least 1000px wide by 500px tall. The standard target is Gemini's 1024x506 preview.
- The image is visually polished: balanced composition, intentional color, clean contrast, and no obvious generation artifacts.
- The image clearly features the Paperclipalypse paperclip stand-up comic on or near a microphone.
- The image includes a visual scene inspired by the winning joke, not a generic or unrelated scene.
- The image is not monochrome or sepia-only unless explicitly requested for that round.
- The image contains no visible prompt labels, layout labels, percentages, watermarks, signatures, or fake filler text.
- Any joke text shown inside the image is legible enough not to distract; if Gemini garbles the text badly, reject and regenerate.
- The exact joke text remains available as HTML on the site even if the image includes stylized text.

You can run the automatic file checks with:

```sh
node scripts/qa-feature-image.mjs --image tmp/gemini-feature-images/2026-06-06-ext-real-2026-06-06.jpg --approved
```

After visual approval, render the episode with the approved preview image:

```sh
node scripts/run-tournament.mjs --episode-file data/inbox/ext-real-2026-06-06.json --feature-image tmp/gemini-feature-images/2026-06-06-ext-real-2026-06-06.jpg --feature-image-qa-approved
```

The runner will copy the approved Gemini image into `site/assets/feature-images/`, attach it to the run JSON, and render it on the home and episode pages.
